# TL;DR

Repeat the last response in plain language.

- Keep it short, concrete, and complete.
- Preserve the important result, what failed or remains uncertain, and any limits on what can happen next.
- Remove jargon, repetition, implementation detail, and internal process unless needed to understand the result.
- Do not invent progress, proof, or next steps.

## Next actions

List only the actions that still need to happen. Say who needs to do each one when that is not obvious.

If nothing remains for this chat to do, say: `You can archive this chat.`

If this chat still owns work, is waiting for a result, or needs a decision, say: `Keep this chat open.`

## TL;DR

End with one sentence that states the outcome and the most important remaining action, if any.
