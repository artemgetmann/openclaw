# Temporary document-creation release gate

After building the Jarvis release candidate and before publishing the Sparkle update, test the packaged application in a clean environment where Codex, Homebrew, and ambient host tools are unavailable. Verify that Jarvis creates valid PDF, DOCX, XLSX, and PPTX files using only bundled dependencies. Remove this temporary checklist item only after that packaged release-candidate proof is recorded.
